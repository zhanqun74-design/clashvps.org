Clash Verge Rev 使用教程：Windows/Mac 下载安装与导入订阅

作者：ClashVPS 编辑部 发布日期：2026年10月22日 适用版本：v2.5.x
5 步用起来
  • 下载：从官方 GitHub Releases 下载，Windows 选 x64-setup.exe，苹果 M 系列芯片选 aarch64.dmg，Intel Mac 选 x64.dmg。
  • 导入订阅：复制机场的订阅链接，粘贴到「订阅」页，点「导入」。
  • 选节点：在「代理」页选择规则模式，测一下延迟，选一个节点。
  • 开代理：打开系统代理开关，浏览器就能访问海外网站了。
  • 按需开 TUN：游戏、命令行等不走系统代理的程序，再开虚拟网卡模式（TUN）。

Clash Verge Rev 是目前 Windows 和 macOS 上最常用的 Clash 客户端之一。它免费、开源，界面是中文，支持一键导入机场订阅。这篇教程从下载安装包开始，一步步讲到导入订阅、选节点、打开代理，最后整理了新手最常遇到的问题和解决方法。

软件界面会随版本更新略有变化，本文按 2026 年 10 月的 v2.5.x 版本编写。如果你看到的按钮位置不完全一样，按名称找即可。

一、Clash Verge Rev 是什么

Clash 本身是一个没有界面的“核心程序”，负责按规则转发网络流量。Clash Verge Rev 是在核心外面套了一层图形界面的客户端，内置的核心是 mihomo（也叫 Clash Meta）。早年流行的 Clash for Windows 已经停止更新，现在桌面端大多改用 Clash Verge Rev。

要注意的是：客户端只是“工具”，本身不带节点。你需要先有一个机场的订阅链接（或自建服务器），导入之后才能使用。订阅链接、节点、规则分流这些概念，可以先看 Clash 是怎么工作的，看完再操作会更顺手。

二、下载哪个安装包

请只从官方渠道下载：Clash Verge Rev 官方 GitHub Releases，或者本站的 客户端下载页（同样指向官方地址）。不要用来路不明的“破解版”“汉化版”，客户端能看到你的全部网络流量，来源不明的安装包风险很大。

进入 Releases 页面后，在最新版本的 Assets（附件）列表里，按你的电脑选择：

你的电脑选择的文件（文件名结尾）说明
普通 Windows 电脑（Intel / AMD 处理器）x64-setup.exe绝大多数人选这个
ARM 处理器的 Windows 电脑（如骁龙笔记本）arm64-setup.exe不确定就选 x64
Windows 安装后打不开x64_fixed_webview2-setup.exe自带 WebView2 运行环境
苹果 M1 / M2 / M3 / M4 芯片的 Macaarch64.dmg2020 年底以后的大部分 Mac
Intel 处理器的 Macx64.dmg较老的 Mac

怎么看 Mac 是哪种芯片：点屏幕左上角苹果图标 →「关于本机」，“芯片”一栏写着 Apple M 开头的就是 M 系列，写着 Intel 的就是 Intel。截至 2026 年 10 月，最新版本是 v2.5.8，Windows 7 已不再支持。

三、Windows 安装步骤

  1. 双击下载好的 setup.exe，按提示点「下一步」完成安装。建议保持默认安装位置（C:\Program Files\Clash Verge），不要装到桌面或“下载”文件夹，否则后面开 TUN 模式时可能因为权限检查失败而用不了。
  2. 如果弹出 Windows 安全提示，点「更多信息 → 仍要运行」。
  3. 安装完成后打开 Clash Verge，主界面左侧是菜单栏，常用的是「代理」「订阅」「设置」几页。

四、macOS 安装步骤

  1. 双击下载好的 .dmg 文件，把 Clash Verge 图标拖到「应用程序（Applications）」文件夹。
  2. 在「应用程序」里打开 Clash Verge。第一次打开如果提示“无法验证开发者”，到「系统设置 → 隐私与安全性」页面底部点「仍要打开」。
  3. 开启系统代理时，系统可能会要求输入电脑的开机密码，这是修改网络设置的正常授权。

如果提示“已损坏，无法打开”，官方说明通常是在旧版本还在运行时安装了新版本导致的。先在菜单栏图标里完全退出 Clash Verge，删除应用后重新安装即可。

五、导入机场订阅

这一步是把机场提供的节点和规则装进客户端。

  1. 复制订阅链接：登录机场官网的用户中心，找到“订阅”或“一键订阅”，选择“复制订阅地址”（有的写作“Clash 订阅”）。订阅链接相当于账号凭证，不要发给别人。
  2. 粘贴并导入：打开 Clash Verge 左侧的「订阅」页，把链接粘贴到顶部的输入框里，点「导入」。
  3. 选中订阅：导入成功后，下方会出现一张订阅卡片，上面显示已用流量和到期时间。点一下这张卡片，让它处于选中（高亮）状态，配置才会生效。

很多机场的用户中心还提供“一键导入到 Clash Verge”按钮，点击后浏览器会询问是否打开 Clash Verge，允许后会自动导入，效果和手动粘贴一样。

订阅卡片上显示的“已用流量”，是机场按节点倍率换算后的扣除量。不同节点扣流量的速度可能不一样，详见 机场倍率是什么。各种客户端导入订阅的通用方法，也可以参考机场笔记的订阅导入教程。

六、选择节点和代理模式

打开左侧的「代理」页，顶部可以切换三种模式：

模式效果建议
规则按订阅里的规则自动分流：国内网站直连，海外网站走节点日常使用选这个
全局所有流量都走你选的节点临时排查问题时用
直连所有流量都不走节点相当于暂时关掉代理

选好模式后，下方会列出机场的节点分组（策略组）。点分组旁边的测速（闪电）图标，可以一次测出所有节点的延迟，然后点击一个延迟较低的节点即可。很多机场还提供“自动选择”分组，会自动切换到延迟最低的节点，新手直接选它也可以。

客户端里显示的延迟是“通过节点访问测试网址”的总耗时，包含握手时间，通常比 ping 值高，只适合在节点之间互相比较。想看懂这些数字，可以读 看懂测速报告的 5 个指标。白天延迟正常、晚上变高，多半是晚高峰拥堵，原理见 为什么一到晚上 9 点网络就变慢。

七、打开系统代理或 TUN 模式

导入订阅、选好节点之后，还要“打开开关”，流量才会真正经过 Clash。有两种方式：

1. 系统代理（日常够用）

在 Clash Verge 的首页或「设置」页，打开「系统代理」开关。它会自动修改电脑的代理设置，让浏览器等遵守系统代理的软件走 Clash。打开后访问一个海外网站，能正常打开就说明成功了。

2. 虚拟网卡模式 / TUN（接管所有程序）

有些程序不理会系统代理，例如部分游戏、命令行工具、某些桌面应用。这时可以打开「虚拟网卡模式」（即 TUN 模式）：Clash 会创建一块虚拟网卡，接管整台电脑的网络流量。

  • Windows：开 TUN 之前，需要先在「设置」里安装服务模式（需要管理员权限）。部分安全软件可能会拦截服务安装，被拦截时需要在安全软件里放行。
  • macOS：打开时按提示输入电脑密码授权即可。

TUN 模式会让系统更新、云盘同步等后台流量也经过 Clash。只要保持「规则」模式，国内流量依然直连、不扣机场流量；但如果切到「全局」，这些流量都会消耗套餐。

八、推荐的几项设置

  • 开机自启 / 静默启动：在「设置」里打开，开机后自动在后台运行，不弹窗口。
  • 自动更新订阅：在订阅卡片上右键 →「编辑信息」，设置更新间隔（例如每 24 小时）。机场更换节点后，客户端会自动同步。
  • 端口：Clash Verge Rev 默认的代理端口是 7897。如果某个软件需要手动填写代理，地址填 127.0.0.1，端口填 7897。
  • 正确退出：关闭窗口只是缩到托盘，并没有退出。需要完全退出时，在托盘（菜单栏）图标上右键选择「退出」，这样系统代理设置会被正常恢复。

总结

Clash Verge Rev 的使用流程可以记成一句话：官方下载 → 导入订阅并选中 → 规则模式选节点 → 打开系统代理。日常上网用系统代理就够了，游戏和命令行工具再开 TUN。遇到问题时，先看是不是安装包选错、订阅没选中，或者没有正常退出导致代理残留，这三种情况占了新手问题的大多数。

常见问题 FAQ

Clash Verge Rev 是免费的吗？

是的。Clash Verge Rev 是在 GitHub 上公开源代码的免费软件，本身不提供节点，需要导入机场或自建服务器的订阅链接才能使用。请只从官方 GitHub Releases 下载，不要使用来路不明的“破解版”“汉化版”。

Windows 应该下载哪个安装包？

绝大多数电脑选文件名带 x64-setup.exe 的安装包。只有骁龙等 ARM 处理器的电脑才选 arm64。如果安装后打不开、只有托盘图标，可以换成文件名带 fixed_webview2 的版本。

系统代理和 TUN 模式有什么区别？

系统代理只对遵守系统代理设置的软件生效，例如浏览器，日常使用开它就够了。TUN 模式（虚拟网卡模式）会接管整台电脑的网络，适合游戏、命令行工具等不走系统代理的程序。Windows 上使用 TUN 需要先安装服务模式。

为什么关掉 Clash 之后就上不了网？

通常是 Clash 没有正常退出，系统代理设置残留了。Windows 打开“设置 → 网络和 Internet → 代理”，在“手动设置代理”里关闭“使用代理服务器”即可恢复。以后退出时请从托盘图标右键选择退出。

导入订阅后节点全部超时怎么办？

先在订阅页手动更新一次订阅，再检查电脑的系统时间是否准确、套餐是否到期或流量是否用完。如果仍然全部超时，可能是机场线路故障或订阅链接已重置，请到机场用户中心复制最新的订阅链接重新导入。
